# Notebook Organizer

### Автор:
Степанова Полина

### Описание:
Консольное приложение для хранения и управления заметками с фильтрацией по тегам и дате, поддержкой Undo (отмены), хранения в JSON, гибкой архитектурой через ООП и полиморфизм (TextNote/VoiceNote).

### Как запустить:
1. Загрузите проект, перейдите в папку с файлами.
2. Запустите команду: notebook.py
3. Следуйте меню для работы с заметками.

### Примеры использования:
- Создайте текстовую или голосовую заметку.
- Отфильтруйте заметки по тегу или дате.
- Используйте Undo для отмены последнего действия.

### Тесты:
- Попробуйте удалить несуществующую заметку — должен быть обработан негативный случай.
- Введите дату в неверном формате — программа должна предупредить.
- Добавьте несколько заметок, воспользуйтесь фильтрацией и отменой.

### Требования:
- Python 3.x
